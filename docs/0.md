# 第0章：Laravel × React 環境構築と疎通確認

## 章の目的

この章では、JobHunt Lite を開発するための土台を作成します。

Laravel と React をそれぞれ作成し、バックエンドとフロントエンドを別々に起動できる状態にします。

最後に、Laravel API を React から呼び出し、画面に `Hello JobHunt API` を表示して、Laravel × React の疎通確認を行います。

---

## 章のゴール

第0章のゴールは、以下の2つです。

```txt
1. Laravel側で /api/hello にアクセスするとJSONが返る

2. React側で localhost:5173 を開くと、
   Laravel APIから取得した Hello JobHunt API が画面に表示される
```

---

## バックエンド確認URL

```txt
http://127.0.0.1:8000/api/hello
```

期待結果：

```json
{
  "message": "Hello JobHunt API"
}
```

---

## フロントエンド確認URL

```txt
http://localhost:5173
```

期待結果：

```txt
JobHunt Lite

Laravelから取得したメッセージ：

```

```txt

→ Laravel APIを直接確認している

```

同じ `Hello JobHunt API` でも、8000番はバックエンド単体確認、5173番はフロントエンド連携確認です。

## 0-6. ReactからLaravel APIをfetchする

### 目安時間

```txt
5分
```

### 目的

ReactからLaravel API `/api/hello` を呼び出し、取得した値を画面に表示します。

### 編集ファイル

```txt
frontend/src/App.tsx
```

### コード

```tsx
import { useEffect, useState } from "react";

function App() {
  const [message, setMessage] = useState("");

  useEffect(() => {
    fetch("http://127.0.0.1:8000/api/hello")
      .then((response) => response.json())
      .then((data) => {
        setMessage(data.message);
      })
      .catch((error) => {
        console.error("API通信エラー:", error);
        setMessage("API通信に失敗しました");
      });
  }, []);

  return (
    <div style={{ padding: "40px", fontFamily: "sans-serif" }}>
      <h1>JobHunt Lite</h1>

      <h2>Laravel API 疎通確認</h2>

      <p>Laravelから取得したメッセージ：</p>

      <strong>{message}</strong>
    </div>
  );
}

export default App;
```

### React起動

```bash
cd ~/Desktop/dev/jobhunt-lite/frontend
npm run dev
```

### 確認URL

```txt
http://localhost:5173
```

### 期待結果

```txt
Hello JobHunt API
```
