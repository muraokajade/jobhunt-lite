# 0章：環境構築とLaravel × React疎通確認

## 目的

JobHunt Lite の開発環境を作成し、Laravel API と React がつながるところまで確認する。

さらに、companiesテーブルを作成し、DBに入れた仮データをLaravel APIからJSONで返すところまで確認する。

---

## この章でやること

```txt
1. jobhunt-lite 作成
2. Git初期化
3. backend Laravel 作成
4. frontend React 作成
5. Laravel API /api/hello 作成
6. Reactから /api/hello をfetch
7. companies テーブル作成
8. Company Model に $fillable を書く
9. tinkerで仮データ投入
10. /api/companies を8000番で確認
```

---

## 0章のゴール

```txt
Laravel と React が別々に起動し、
ReactからLaravel APIを呼び出せる状態を作る。

さらに、DBに保存した企業データを
/api/companies でJSONとして確認できる状態にする。
```

---

## 0章の終了ライン

```txt
http://127.0.0.1:8000/api/companies
```

を開いたときに、DBに保存した企業データがJSONで返る。
