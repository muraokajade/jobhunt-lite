# 第1章：companiesテーブル作成と企業一覧表示

## 章の目的

この章では、JobHunt Lite の中心データである「企業情報」を扱うための土台を作成します。

Laravel側では `companies` テーブルを作成し、企業データをDBに保存できる状態にします。

その後、Laravel API から企業一覧をJSONで返し、React側でそのデータを一覧表示します。

---

## 章のゴール

第1章のゴールは、以下の状態を作ることです。

```txt
DBに保存した企業データが、
Laravel APIを通してJSONで返り、
React画面に企業一覧として表示される
```

---

## この章でやること

```txt
1. Company Model / Migration / Factory を作成する
2. companiesテーブルを定義する
3. migrateでDBに反映する
4. Company Model に $fillable を設定する
5. CompanyController を作成する
6. apiResource でCRUDルートを作成する
7. index メソッドで企業一覧JSONを返す
8. tinkerで仮データを登録する
9. /api/companies をブラウザで確認する
10. Tailwind CSS を導入する
11. Reactでmock一覧を表示する
12. ReactをLaravel APIに差し替える
```

---

## この章でやらないこと

```txt
store
update
delete
検索
詳細モーダル
認証
FormRequest
CompanyResource
Feature Test
コンポーネント分割
```

これらは次章以降で扱います。

第1章では、まず「DBの企業データをReact画面に表示する」ところまでに絞ります。

# 1-2. companiesテーブルを定義する

## 目安時間

```txt
7分
```

## 目的

JobHunt Liteで管理する企業情報を保存するために、`companies` テーブルのカラムを定義します。

---

## 編集ファイル

```txt
database/migrations/xxxx_xx_xx_xxxxxx_create_companies_table.php
```

---

## コード

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    /**
     * companiesテーブルを作成する処理
     */
    public function up(): void
    {
        Schema::create('companies', function (Blueprint $table) {
            $table->id();

            // ログインユーザーID
            // 認証は後で実装するため、今はnullを許可する
            $table->foreignId('user_id')
                ->nullable()
                ->constrained()
                ->cascadeOnDelete();

            // 企業名
            $table->string('name');

            // 応募媒体
            $table->string('media')->nullable();

            // 優先度・志望度
            $table->string('priority')->nullable();

            // 応募ステータス
            $table->string('status')->default('応募済み');

            // 応募日
            $table->date('applied_date')->nullable();

            // 面談・面接日時
            $table->dateTime('interview_date')->nullable();

            // 求人URL
            $table->text('job_url')->nullable();

            // 面接URL
            $table->text('interview_url')->nullable();

            // メモ
            $table->text('memo')->nullable();

            // 次にやること
            $table->string('next_action')->nullable();

            // 書類選考結果
            $table->string('document_result')->nullable();

            // 一次面接結果
            $table->string('first_interview_result')->nullable();

            // 二次面接結果
            $table->string('second_interview_result')->nullable();

            // 最終面接結果
            $table->string('final_result')->nullable();

            // 落選ステージ
            $table->string('rejection_stage')->nullable();

            // お気に入り
            $table->boolean('is_favorite')->default(false);

            // created_at / updated_at
            $table->timestamps();
        });
    }

    /**
     * companiesテーブルを削除する処理
     */
    public function down(): void
    {
        Schema::dropIfExists('companies');
    }
};
```

---

## 主なカラムの意味

| カラム名                | 型        | 意味           |
| ----------------------- | --------- | -------------- |
| id                      | bigint    | 主キー         |
| user_id                 | foreignId | ユーザーID     |
| name                    | string    | 企業名         |
| media                   | string    | 応募媒体       |
| priority                | string    | 優先度・志望度 |
| status                  | string    | 応募ステータス |
| applied_date            | date      | 応募日         |
| interview_date          | dateTime  | 面談・面接日時 |
| job_url                 | text      | 求人URL        |
| interview_url           | text      | 面接URL        |
| memo                    | text      | メモ           |
| next_action             | string    | 次にやること   |
| document_result         | string    | 書類選考結果   |
| first_interview_result  | string    | 一次面接結果   |
| second_interview_result | string    | 二次面接結果   |
| final_result            | string    | 最終面接結果   |
| rejection_stage         | string    | 落選ステージ   |
| is_favorite             | boolean   | お気に入り     |
| created_at              | timestamp | 作成日時       |
| updated_at              | timestamp | 更新日時       |

---

## 補足：nullableとは

```php
$table->string('media')->nullable();
```

`nullable()` は、空でも保存できるという意味です。

企業名は必須にしますが、媒体・応募日・メモなどは後から入力する場合もあるため、空を許可しています。

---

## 補足：認証はまだ実装しない

`user_id` は用意していますが、この章では認証はまだ扱いません。

```php
$table->foreignId('user_id')
    ->nullable()
    ->constrained()
    ->cascadeOnDelete();
```

認証を後で追加したときに、どのユーザーが登録した企業なのかを管理できるようにするため、先にカラムだけ用意しています。

---

## このレクチャーのゴール

```txt
companiesテーブルの設計をmigrationに書ける
```


---

## migrateの意味

```txt
migrationファイルに書いたテーブル設計をDBに反映するコマンド
```

この時点で、DBに `companies` テーブルが作成されます。

---

## 編集ファイル

```txt
app/Models/Company.php
```

---

## コード

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Company extends Model
{
    use HasFactory;

    /**
     * 一括登録を許可するカラム
     */
    protected $fillable = [
        'user_id',
        'name',
        'media',
        'priority',
        'status',
        'applied_date',
        'interview_date',
        'job_url',
        'interview_url',
        'memo',
        'next_action',
        'document_result',
        'first_interview_result',
        'second_interview_result',
        'final_result',
        'rejection_stage',
        'is_favorite',
    ];
}
```

---

## $fillable の意味

```txt
create() や update() でまとめて保存してよいカラムを指定する設定
```

Laravelでは安全のため、何でも自由に一括保存できるわけではありません。

例えば、以下のように `Company::create()` を使う場合、

```php
Company::create([
    'name' => 'サンプル株式会社',
    'status' => '応募済み',
]);
```

Model側で `$fillable` に `name` や `status` を書いておく必要があります。

---

## よく出るエラー

```txt
Illuminate\Database\Eloquent\MassAssignmentException
Add [name] to fillable property to allow mass assignment on [App\Models\Company].
```

---

## エラーの意味

```txt
Company::create() で name を保存しようとしたが、
Company Model の $fillable に name が書かれていないため保存できない
```

---

## このレクチャーのゴール

```txt
companiesテーブルをDBに作成し、
Company::create() で保存できる準備ができる
```

# 1-8. ReactをLaravel APIに差し替える

## 目安時間

```txt
8分
```

## 目的

React内の仮データ表示から、Laravel APIで取得したDBデータ表示へ切り替えます。

これにより、DBに保存した企業データがReact画面に表示されるようになります。

---

## 編集ファイル

```txt
frontend/src/App.tsx
```

---

## コード

```tsx
import { useEffect, useState } from "react";

type Company = {
  id: number;
  user_id: number | null;
  name: string;
  media: string | null;
  priority: string | null;
  status: string;
  applied_date: string | null;
  interview_date: string | null;
  job_url: string | null;
  interview_url: string | null;
  memo: string | null;
  next_action: string | null;
  document_result: string | null;
  first_interview_result: string | null;
  second_interview_result: string | null;
  final_result: string | null;
  rejection_stage: string | null;
  is_favorite: boolean;
  created_at: string;
  updated_at: string;
};

const API_URL = "http://127.0.0.1:8000/api/companies";

function App() {
  const [companies, setCompanies] = useState<Company[]>([]);

  const fetchCompanies = async () => {
    const res = await fetch(API_URL);
    const json = await res.json();

    setCompanies(json);
  };

  useEffect(() => {
    fetchCompanies();
  }, []);

  return (
    <div className="min-h-screen bg-slate-100 p-8 text-slate-900">
      <div className="mx-auto max-w-5xl rounded-xl bg-white p-6 shadow-sm">
        <h1 className="text-2xl font-bold">JobHunt Lite</h1>

        <p className="mt-2 text-sm text-slate-600">
          Laravel APIから取得した企業一覧を表示します。
        </p>

        <div className="mt-6">
          <div className="flex items-center justify-between">
            <h2 className="text-lg font-bold">企業一覧</h2>
            <p className="text-sm text-slate-500">{companies.length}件</p>
          </div>

          {companies.length === 0 ? (
            <p className="mt-4 text-sm text-slate-500">
              企業データがありません。
            </p>
          ) : (
            <table className="mt-4 w-full border-collapse text-sm">
              <thead>
                <tr className="bg-slate-900 text-white">
                  <th className="border px-4 py-2 text-left">企業名</th>
                  <th className="border px-4 py-2 text-left">媒体</th>
                  <th className="border px-4 py-2 text-left">志望度</th>
                  <th className="border px-4 py-2 text-left">状況</th>
                  <th className="border px-4 py-2 text-left">応募日</th>
                  <th className="border px-4 py-2 text-left">メモ</th>
                </tr>
              </thead>

              <tbody>
                {companies.map((company) => (
                  <tr key={company.id}>
                    <td className="border px-4 py-2 font-bold">
                      {company.name}
                    </td>
                    <td className="border px-4 py-2">{company.media ?? "-"}</td>
                    <td className="border px-4 py-2">
                      {company.priority ?? "-"}
                    </td>
                    <td className="border px-4 py-2">{company.status}</td>
                    <td className="border px-4 py-2">
                      {company.applied_date ?? "-"}
                    </td>
                    <td className="border px-4 py-2">{company.memo ?? "-"}</td>
                  </tr>
                ))}
              </tbody>
            </table>
          )}
        </div>
      </div>
    </div>
  );
}

export default App;
```
