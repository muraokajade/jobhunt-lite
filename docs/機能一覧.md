## 検索・絞り込み

Q1. 一覧取得なのに、なぜいきなり get() しないのでしょうか？

Q2. $query = Company::query() は、DBの結果ですか？
それとも、検索条件を組み立てている途中のものですか？

Q3. keyword がある時だけ検索条件を追加したい場合、
if文の中で何を $query に足せばよいでしょうか？

Q4. status や media が空の時も where をかけるべきでしょうか？

Q5. name または memo に keyword が含まれる企業を探したい場合、
where と orWhere のどちらを使うべきでしょうか？

Q6. 最後に get() を書かないと、何が起きるでしょうか？

Q7. CompanyResource::collection() に渡すべきなのは、
$query そのものですか？ それとも get() した結果ですか？

最初に「自分の企業だけ」という土台条件を作る。
そのあと、keyword があれば keyword 条件を追加する。
status があれば status 条件を追加する。
media があれば media 条件を追加する。
最後に get() で初めてDBから取得する。
